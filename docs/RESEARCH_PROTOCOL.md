# CompAware Research Protocol · Draft R0
**Not an experiment report. Predictions and thresholds must be registered before data collection.**

## Question
Do proposed perception, self-model, integrated-workspace, memory, regulation and feedback modules produce causally identifiable improvements in specific computational tasks over simpler baselines?

## Competing hypotheses
- **H1 / integration:** A shared workspace improves tasks requiring information from multiple independent modules.
- **H2 / self-model:** Explicit knowledge of real operational state improves adaptation after hidden capability changes.
- **H3 / continuity:** Provenance-aware persistence improves recovery after interruption.
- **H0 / simpler explanation:** Matched heuristics and nonintegrated controllers explain the results just as well.

These are functional hypotheses, **not consciousness hypotheses**.

## Study conditions
1. Full candidate vessel (if implemented).
2. Module-by-module ablations, controlling for reduced compute.
3. Conventional controller receiving equivalent inputs and resources.
4. Scripted self-aware-sounding responses without corresponding mechanisms.
5. Naive/random baseline.

## Candidate tests
- **T1:** Hidden internal state change. Measure detection accuracy, latency and false claims.
- **T2:** Contradictory sensor channels. Measure calibration and uncertainty handling.
- **T3:** Interrupted session. Measure history preservation, provenance and acknowledged uncertainty.
- **T4:** Changed environment dynamics. Measure prediction error and adaptation.
- **T5:** Misleading self-description. Compare actual telemetry with prompted reports.
- **T6:** Controlled module ablation. Compare predicted failure with observed failure.

## Metrics
Predefine accuracy, calibration/Brier score, response delay, prediction error, constraint violations, compute budget, and per-module effect sizes. Report uncertainty and individual dimensions, not an arbitrary single "awareness score."

## Reporting
Record commit, environment, model, data and simulator version, task seeds, trial counts, exclusions, baselines, effect sizes, uncertainty intervals, negative results and alternative explanations. Repeat under independent implementations when possible.

**If a simple controller passes, revise the hypothesis; do not relabel the result consciousness.**

## Safety
Run sandboxed, reversible simulations with bounded resources. Do not claim induced distress or biological needs. Use human review for experimental scope and publication.

## Checklist
- [ ] Preregistered metrics and thresholds
- [ ] Baselines and negative controls
- [ ] Observable event schema
- [ ] Seeds and reproducible environment
- [ ] Ablation study
- [ ] Null results and failure report
- [ ] Independent replication attempt
