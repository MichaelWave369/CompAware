# CompAware
### A different substrate. A question of its own.

**CompAware** is a Φ369 Labs open research initiative investigating **Computational Awareness on computational systems' own terms**.

> Define nothing by imitation. Discover through observation.

**Our question:** What can computational systems detect, model, integrate, regulate, remember, and adapt to about their own operation and environment? Are these capacities best understood separately or as a useful distinct construct?

**Our boundary:** We are **not** trying to prove that AI is conscious, subjectively experiencing, alive, or deserving of legal personhood. Nor do we assume a computationally aware system exists already. Human consciousness is **not** our measuring stick or success criterion. Functional capacities are testable; interpretations remain open.

## Live React site

A Vite + React research website is included in src/. It has two separate experiences: an illustrative seven-layer **architecture explorer**, and a real, bounded, rule-based **Haven Lab simulator** with instrumentation, baseline mode, sensor faults and memory-only checkpoints. Neither is an AI agent or awareness detector. Rung 2 adds a **deterministic comparative study** with the same sensor reports for a self-model, a one-bit last-report baseline and two constant baselines. The site can export a transparent JSON trial receipt; no claim of awareness follows from a result. The optional **Silicon Cosmology Atlas** maps seven physical/environmental research questions to the existing CA-V0 modules, with proposed tests and simple controls. It is an interpretive guide, not a live sensor or another experimental result. **Rung 3 Noisy Lab** adds a separate exploratory simulator with imperfect binary indicators, a recheck cost, four baseline policies, and an exportable per-tick receipt. Results are sensitive to explicitly chosen costs and assumptions. **Rung 4 Calibration Lab** implements a direct response to CA-SC-02: unknown and drifting sensor reliability, paid independent verification, adaptive and simple calibration baselines, and separately reported exploratory seed partitions. **Rung 5 Witness Bench** answers CA-SC-03 using two distinct hidden worlds with the exact same paired reports, fallible references, common-cause errors and timestamp skew. **CA-SC-04** adds an expandable analytical three-witness explorer showing that even a complete matching triple-report distribution may not identify source accuracy when a hidden common failure mechanism is possible. It compares simple rules and makes no claims about machine consciousness. **Rung 6 Causal Provenance Lab** implements CA-SC-04's three-witness counterexample with experimental anchors, corrupted and copied anchors, effective and placebo isolation, cautious baselines, and audit receipts. These remain simulated models, not physical measurements. **Rung 7 Transportability Lab** tests CA-SC-05's matched pre/post/return intervention worlds, controlled-input probes, deliberately corrupted input certificates and a probe-only calibration shift. It preserves a no-identification control and exports scorer-auditable receipts.

Run locally:

npm run dev
npm run check
~~~

## Roadmap

**00 Observe:** characterize actual capabilities, limits and state instrumentation.

**01 Specify:** preregister definitions, predicted outcomes and simpler explanations.

**02 Challenge:** ablations, hidden changes, false cues, matched baselines, negative controls.

**03 Replicate:** report code, methods, negative results and independent findings.

**CA-Haven Rung 1** adds an instrumented software vessel whose behavior comes entirely from visible rules, with no AI model inference. It is an experimental test harness, not evidence of Computational Awareness. No single score will be called an "awareness level" without validated meaning.
