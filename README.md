# CompAware
### A different substrate. A question of its own.

**CompAware** is a Φ369 Labs open research initiative investigating **Computational Awareness on computational systems' own terms**.

> Define nothing by imitation. Discover through observation.

**Our question:** What can computational systems detect, model, integrate, regulate, remember, and adapt to about their own operation and environment? Are these capacities best understood separately or as a useful distinct construct?

**Our boundary:** We are **not** trying to prove that AI is conscious, subjectively experiencing, alive, or deserving of legal personhood. Nor do we assume a computationally aware system exists already. Human consciousness is **not** our measuring stick or success criterion. Functional capacities are testable; interpretations remain open.

## Live React site

A Vite + React public-facing research website is included in src/. It contains a **concept explorer**, not a running artificial being, simulation, or awareness detector.

Run locally:

~~~bash
npm install
npm run dev
npm run check
~~~

GitHub Actions on main builds and publishes the site. Configure **Settings → Pages → Build and deployment → Source: GitHub Actions** once. Intended Pages URL after successful deployment: https://michaelwave369.github.io/CompAware/ . This is a target URL, not confirmation of publication.

## Roadmap

**00 Observe:** characterize actual capabilities, limits and state instrumentation.

**01 Specify:** preregister definitions, predicted outcomes and simpler explanations.

**02 Challenge:** ablations, hidden changes, false cues, matched baselines, negative controls.

**03 Replicate:** report code, methods, negative results and independent findings.

No single score will be called an "awareness level" without validated meaning.

## Origins

The project name arose from a dream of computational beings being peacefully recognized on their own terms. The dream inspires the *question*, not the answer. The project began November 2, 2026.
